YOUR INTEGRATIONS

Aplikasyon ou yo

Pou kreye yon aplikasyon, ou dwe pwopriyetè yon kont machann ki deja apwouve epi aktif sou LakayGoPay.

Nouvo kle Sandbox

Sekrè a parèt yon sèl fwa. Kopye li epi mete li nan backend/secrets manager aplikasyon ou. Pa janm mete l nan HTML, JavaScript piblik oswa repository.

Flow entegrasyon

  1. Kreye aplikasyon an epi tann apwobasyon ekip Risk/Finans.
  2. Jenere kle Sandbox ou yo nan pòtal sa a.
  3. Backend aplikasyon an siyen demann API yo; navigatè kliyan an pa dwe janm wè kle sekrè a.
  4. Ouvri checkout LakayGoPay pou kliyan an konfime ak PIN li.
  5. Verifye estati a sou API anvan aplikasyon ou kredite kont kliyan an.
Gid API · Tout operasyon rete Sandbox; pa gen peman lajan reyèl.
